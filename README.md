# Clanker clanker; 

Clanker is a AI assisted repository development application, which came into being to address a loosely defined set of grievances and pitfalls of process, as experienced by its author on his vibecoding journeys.  

The subject of application is the repository, a version controlled collection of files. 
Most often this will be source code files which make up a codebase, but it is thought that a repository may concern itself with a wider array of content types.

The application promotes a semistructured workflow, where the user is in charge and the AI is a consultant and workhorse.

### Complaints of the vibecoding solo developer

#### LLM Peculiarities

Large language models are a great thing.  
Free and readily available, they enable the people of the world not only to learn and explore, but also to work and be productive.  
  
For the vibecoder in particular, their significance cannot be overstated.  
To him the LLM is like the sun in the sky, and absent its brilliant radiance he would walk in darkness, desperately succumbing to practices of stackexchange-browsing, book-reading or perhaps even diligent study.

But much like his brother, the sunbather, the vibecoder cannot afford to be careless and uneducated.  
To safely get the most out of the interaction, he needs to develop a solid understanding of how his sungods works.
Here follows my take:

At their core, the familiar services of ChatGPT / Grok / Gemini and others, can be understood as harness controlled next token generators.
The harness is just some application, tasked with orchestrating the process:
1. Receive some input from a user: 'Hello LLM - how are you?'
2. Translate the input into a LLM friendly token representation: [..., 5468,78542, 15292, 231]
3. Feed the input to the LLM, receive a generated token in response (lets say '6719')
4. Append the generated token to the list of tokens: [..., 5468,78542, 15292, 231, 6719]
5. Repeat steps 3-4 until the token is a special *stop* token is emitted, at which point the generated tokens are translated back into text and returned to the user (unless already streamed).

At the time of generation, there is nothing to distinguish the original input tokens (the users prompt), and those which were generated by the LLM.  
And even if there was, the LLM is not a sentient being with a theory of mind keping track of who said what when.
It is simply a next token generator, iteratively calculating the most likely token to follow the input seen thus far, given the patterns observed in the data used to train it.

#### 'Architecture' - a bad word

- explain high/low split -> in conclusion say 'we need nested approach'
- declarative config / assets, app as interpreter (?)

Clanker was unifile
  - let the llm see the whole thing - correct context 
  - easy to drop off in the browser - ease of prompting

It held out for a while, but eventually..
- certain members became config / assets
- other members became python files of their own

In an attempt to retain the advantages of the unifile, a 'wheat and chaff' (or shit and cinnamon) split emerged:
- Let certain file contain high signal business logic and similar, to expose the workings of the app in an information dense manner.
- And other files contain the boilerplate, the low level transformations etc

In conversations with llm's, this was identified as the *Ports and Adapters* architecture:
- namedrop some guys
- explain in own words what that is about
- explain benefit it provides in selecting assets to form a proper prompt context for an llm

Then explain the members of the codebase on those terms.

### Installation & Prerequisites

The Clanker install process:
1. Clone the repository
'''bash
git clone https://github.com/Iannen/Clanker-clanker.git
cd Clanker-clanker
'''
2. Install python
3. then install ruamel.yaml, a python add-on
4. Configure a shortcut, I use 'clank'
  - Linux: Symlink in /usr/local/bin
  - Windows: PowerShell profile alias or doskey shortcut
  - macOS: Standard zsh alias in ~/.zshrc or /usr/local/bin symlink
5. then enter the repository directory
  - input your shortcut
  - et voila

For instructions beyond this - consult a Clanker ;)
